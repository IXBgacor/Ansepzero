# Aset visual v0.6
Seluruh visual dibuat dari kode (Canvas 2D) — tidak ada berkas gambar atau font eksternal, tidak ada aset berlisensi pihak ketiga: petak (plaza, ladang, area aman), objek (rumah×3, balai desa, tenda×3, kios×2, sumur, lampu, bangku, pagar, bendera, peti, jerami), properti POI (peta evakuasi, kentongan, papan pengumuman, papan titik kumpul), warga baru (8 palet), helikopter (2 bingkai rotor) + ember, mobil pemadam, ikon efek (burung, kilau, hati, centang, silang, seru, pin, surat, koin, tetes, tunas) dan **ikon GUI** (suara, bisu, layar penuh, jeda, daftar, bintang, centang, peringatan, minimize/expand, bendera, orang, panah, sertifikat, kotak, gembok, putar, medali, buku). Font: tumpukan monospace tebal bawaan sistem (`ui-monospace`, "Cascadia Mono", "Roboto Mono", "Courier New") — **bukan font pixel sejati**, karena tidak ada berkas font yang boleh/bisa diunduh di lingkungan pembuatan.
