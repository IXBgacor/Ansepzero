Kebijakan privasi

Ringkasan praktik data AnsepZero. Ini bukan dokumen hukum; pengelola perlu menyesuaikannya dengan ketentuan yang berlaku sebelum publikasi.

Data yang disimpan

Nama tampilan yang kamu pilih, ID pemain acak, jawaban kuis, skor, waktu pengerjaan, dan progres misi. Kami tidak meminta email, nomor telepon, atau nama asli. Jangan memakai data pribadi sebagai nama tampilan.

Laporan kejadian: deskripsi, keterangan lokasi, koordinat GPS (hanya jika kamu menekan tombol GPS), dan foto (jika diaktifkan dan kamu mengunggahnya). Lokasi dan foto hanya dilihat admin, tidak ditampilkan ke publik.

Penghitung kunjungan menyimpan jumlah per hari tanpa identitas. Untuk membatasi spam, server menyimpan kunci pembatas yang di-hash dari alamat jaringan dan menghapusnya secara berkala; alamat jaringan tidak disimpan dalam bentuk asli.

Di perangkatmu

Kode pemulihan dan progres game disimpan di penyimpanan browser. Siapa pun yang memegang kode pemulihan dapat melanjutkan progresmu, jadi jangan membagikannya.

Penjaga Hutan AI

Pertanyaan yang kamu ketik di halaman Penjaga Hutan AI dikirim lewat server AnsepZero ke layanan model bahasa (Google Gemini, Cloudflare Workers AI, atau penyedia lain yang dipasang pengelola) hanya untuk membuat jawaban. AnsepZero tidak menyimpan isi percakapan di database dan tidak mengaitkannya dengan nama tampilan, skor, atau kode pemulihanmu. Percakapan disimpan sementara di perangkatmu dan hilang saat tab ditutup atau tombol "Percakapan baru" ditekan. Server hanya menyimpan penghitung pembatas laju yang di-hash. Penyedia layanan AI dapat memiliki kebijakan datanya sendiri. Jangan menulis nama lengkap, nomor telepon, alamat, atau data pribadi lain di kolom pertanyaan.

Papan skor

Nama tampilan, skor, dan pencapaian tampil publik. Nama tampilan bukan bukti identitas siapa pun.

Menghapus data

Di halaman Kuis, tombol "Hapus data saya" menghapus semua data pemain (skor, jawaban, progres, papan skor) dari server. Penghapusan laporan kejadian dilakukan admin; hubungi pengelola situs dengan menyebut kode laporanmu. Tidak ada penghapusan otomatis berdasarkan waktu saat ini.
